# Agitator sizing methods (example)

Use DIR working volume \(V\) and fluid properties when present. Label estimates.

## Impeller diameter

\(D \approx T/3\) for a single hydrofoil in a baffled vessel unless DIR or catalog
says otherwise. \(T\) is vessel inside diameter.

## Tip speed

\(v_t = \pi N D\). Report m/s. Do not treat a generic tip-speed target as a
guaranteed blend-time result.

## Power

\(P = N_p \rho N^3 D^5\) when a power number is known; otherwise use a labeled
P/V range for the duty and flag vendor confirmation of impeller hydraulics.

## Torque

\(T_q = P / \omega\) with \(\omega = 2\pi N\). Motor nameplate includes a service
factor; gearbox rating is vendor-confirmed.
